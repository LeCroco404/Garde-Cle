# Garde-Clé

Autodiagnostic cyber gratuit pour les petites structures sans service informatique
(cabinets médicaux, associations, TPE) : une quinzaine de questions simples, un score
de maturité et les 5 actions à mener en priorité, expliquées sans jargon.

Tout le calcul se fait dans le navigateur : aucune réponse n'est envoyée ni stockée.

Projet en cours de développement.
